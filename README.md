# Readaloud 문서 낭독기

Word(.docx)나 LaTeX(.tex) 문서를 열어 브라우저 음성으로 읽어 주는 페이지입니다. 기본으로 들어 있는 문서는 없습니다.

## 쓰는 법

1. `index.html`을 브라우저로 엽니다. GitHub Pages를 켰다면 `https://<사용자명>.github.io/readaloud/`로 엽니다.
2. 파일을 끌어다 놓거나 **파일 열기**로 .docx나 .tex를 고릅니다.
3. **재생**을 누르거나 아무 문장이나 누르면 그 문장부터 읽습니다.

- **이동:** 목차로 절을 건너뜁니다. 스페이스는 재생·정지, ←·→는 이전·다음 문장입니다.
- **설정:**
  - 언어: 자동, 한국어, English
  - 음성
  - 속도: 0.6–2배
  - 표·그림 제목, 표 내용, 주를 읽을지
  - 괄호 속 참조("(Section 5.4)", "(표 3)", "[12]")를 건너뛸지
- **저장:** 마지막 문서와 위치는 이 브라우저에만 남습니다. 다음에 열면 "이어 듣기"로 고를 수 있고, "기록 지우기"로 지울 수 있습니다.

## 문서를 읽는 방식

- **docx**
  - 제목 1–3 스타일을 목차로 씁니다.
  - 표는 화면에 보이고, "표 내용"을 켜면 행 단위로 읽습니다.
  - 각주와 미주는 문서 끝 "주"에 모입니다.
  - 그림과 수식 개체는 건너뜁니다.
  - 예전 .doc 형식은 읽지 못하니 .docx로 저장해서 여세요.
- **tex**
  - `\section`, `\subsection`, `\subsubsection`을 목차로 씁니다. `abstract` 환경은 "Abstract"로 둡니다.
  - 수식 환경(`equation`, `align` 등)과 `\[ \]`는 건너뜁니다. 본문 속 `$…$`는 기호로 바꿔 읽습니다(예: `\theta` → θ → "theta"·"세타").
  - 그림·표 환경은 `\caption`만 남깁니다. `\cite`, `\ref`, `\label`은 지웁니다. `\footnote`는 "주"로 옮깁니다.
  - `\input`·`\include`로 불러오는 다른 파일은 포함되지 않으니, 한 파일로 합친 .tex를 여세요.
- **음성:**
  - 긴 문장은 쉼표 단위로 나눠 읽습니다. Chrome이 14초가 넘는 발화를 끊는 문제 때문입니다.
  - 한국어 문서에서 "1958–2023"은 "1958에서 2023"으로, 영어 문서에서는 "1958 to 2023"으로 읽습니다.

## 구성과 라이선스

- `index.html`: 화면과 낭독 기능 전부. 서버, 빌드 도구, API 키가 필요 없습니다.
- `vendor/mammoth.browser.min.js`: docx를 브라우저 안에서 변환하는 mammoth 1.13.0입니다. BSD-2-Clause이며, 라이선스 전문은 `vendor/mammoth-LICENSE.txt`에 있습니다.
- **음성:** 브라우저의 Web Speech API(`speechSynthesis`)입니다. 기기와 브라우저에 설치된 음성을 씁니다. 데스크톱 Edge에서 고품질(Natural) 음성이 가장 많이 나오고, Android용 Edge는 음성 목록을 주지 않습니다.
- **글꼴:** Google Fonts의 Noto Serif KR과 IBM Plex Sans KR입니다. 둘 다 SIL Open Font License 1.1이고, 인터넷이 없으면 기기의 기본 글꼴로 보입니다.
- **개인정보:** 연 파일은 이 브라우저 안에서만 처리하고 어디로도 보내지 않습니다.
